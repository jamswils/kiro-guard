Unlock with a Kiro Guard passphrase

An alternative to the Windows password prompt: nothing to fight for focus, works offline. Only a salted hash is stored (PBKDF2-SHA256, 300,000 rounds). After 5 wrong tries the lock screen offers your recovery question.

Show what KiroCrew is doing on the lock screen

Kiro Guard asks the KiroCrew host for a read-only activity summary while the screen is locked: which chats are moving, whether Kiro is replying or running tools, how many agents are running. It never reads message content; chat titles are the only text shown.
